# Human-Designed Visual Quality Skill

## When to Use
Apply this skill during design conception, layout drafting, copywriting, and visual refinement to ensure the site exhibits genuine studio-grade craftsmanship.

## Implementation Instructions
1. **Banned AI UI Clichés**:
   - NO generic purple/pink glowing blur blobs scattered indiscriminately.
   - NO cookie-cutter 3-column cards with identical padding and icons.
   - NO arbitrary percentage dials (e.g., "Python 94%", "Design 88%").
   - NO meaningless floating particle meshes or ungrounded 3D models.
   - NO generic placeholder marketing phrases ("Passionate about crafting scalable, user-centric solutions").
2. **Authentic Human Copywriting**:
   - Root every claim strictly in Mohamed Abdelhamid's verified academic and engineering record (The British University in Egypt, Computer Engineering, Clowdy assistant, embedded systems, real commercial design).
   - Use direct, confident, concise language.
3. **Intentional Asymmetry & Rhythm**:
   - Vary structural density between sections (e.g., dense technical taxonomy grid followed by airy, monumental editorial call-to-action).
   - Use bespoke numbered indices (`01`, `02`, `03`...) and crisp hairline rules.

## Completion Criteria
- The website feels like it was designed by an independent creative studio with distinct taste.
- Copy is authentic, concise, and professional.

# From-Scratch Design Directives

## 1. Zero Inheritance Principle
- Never import, copy, or refactor legacy components from previous designs.
- Start every layout from a pure, clean black canvas (`#000000`).
- Reject all boilerplate UI conventions: rounded card grids, centered hero templates, floating gradient spheres, and cookie-cutter SaaS layouts.

## 2. Experimental Editorial Layouts
- **Monumental Typography**: Use massive typographic scale with extreme weight contrast. Display text commands the space while mono metadata grounds the composition.
- **Asymmetric Tension**: Off-center hero compositions, irregular column spans (e.g., 7/5 or 8/4 grid splits), and deliberate negative space.
- **Architectural Lines**: Use razor-thin 1px borders (`#1f1f1f` to `#262626`) to partition content like an editorial monograph or museum catalog.

## 3. Color & Surface Architecture
- **Canvas Base**: `#000000` (Pitch Black).
- **Primary Text**: `#ffffff` (High-contrast pure white).
- **Secondary Text**: `#a1a1aa` (Zinc-400) and `#71717a` (Zinc-500).
- **Accents**: Muted warm brass (`#d4af37` / `#e5c07b`) or subtle emerald (`#10b981`) for live indicators.
- **Surface Elevation**: `#09090b` (Deep Zinc-950) with 1px border `#18181b`.
